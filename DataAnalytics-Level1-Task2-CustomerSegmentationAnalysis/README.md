Objective
The objective of this project is to apply K-Means clustering to segment an e-commerce company's customer base based on purchasing behaviour and identify distinct customer groups for targeted marketing strategies.

Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- K-Means Clustering
- RFM Analysis


Dataset
The project uses the Online Retail dataset containing transactional data from an e-commerce business.


Methodology
1. Data Loading and Inspection
2. Data Cleaning
3. Customer Purchase Summary
4. RFM Analysis
5. Data Standardization using StandardScaler
6. Elbow Method
7. K-Means Clustering
8. Cluster Profiling
9. Customer Segment Visualization
10. Marketing Recommendations


Customer Segments
- Regular Customers
- At-Risk Customers
- VIP Customers
- Loyal High-Value Customers

Key Insights
The customer base was segmented into four groups based on Recency, Frequency, and Monetary value. The segments show different purchasing behaviours and can help the business create targeted marketing strategies.

Conclusion
RFM-based K-Means clustering provides useful customer segmentation insights that can support customer retention, loyalty programs, personalized promotions, and high-value customer management.
