# Wine Quality Prediction

## OASIS INFOBYTE — Data Analytics Internship

Track: Data Analytics  
Level: Level 2  
Task: Task 2 — Wine Quality Prediction

## Objective
The objective of this project is to predict wine quality categories based on physicochemical properties using machine learning classification models.

## Models Used
- Random Forest Classifier
- SGD Classifier
- Support Vector Classifier (SVC)

## Dataset
Wine Quality — Red Wine dataset from the UCI Machine Learning Repository.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Result
Among the three tested models, Random Forest achieved the best overall performance with an accuracy of 86.56% and an F1-score of 84.07%.

## Conclusion
Random Forest was selected as the most suitable model among the tested classifiers because it achieved the highest overall accuracy and F1-score.
