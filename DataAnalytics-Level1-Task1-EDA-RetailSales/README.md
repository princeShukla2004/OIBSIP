# EDA on Retail Sales Data

**Task:** Level 1 - Task 1: EDA on Retail Sales Data

## Objective

The objective of this project is to perform Exploratory Data Analysis
(EDA) on retail sales data to understand sales patterns, customer
behaviour, product category performance, and business insights.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The dataset contains retail transaction information including transaction
details, customer demographics, product categories, quantity, price per
unit, and total transaction amount.

## Analysis Performed

- Dataset inspection and data quality checking
- Descriptive statistics
- Monthly and quarterly sales trends
- Customer age group distribution
- Gender analysis
- Product category analysis
- Revenue by product category
- Correlation analysis using a heatmap
- Average spending by age group
- Business recommendations

## Dataset Limitation

The dataset does not contain individual product names. Therefore, the
analysis is performed at the Product Category level instead of individual
product level.
